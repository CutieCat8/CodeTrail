## A. Desktop และเส้นทางหลัก

### A1 — Dashboard

- หน้า/hash: `#dashboard`
- Viewport: `1440 × 900` แล้วตรวจซ้ำที่ `1280 × 800`
- ขั้นตอน:
  1. เปิดด้วย profile ที่ยังไม่มี progress
  2. เปลี่ยนโหมด Full-stack / Java & OOP / ผสม
  3. รีเฟรชหน้า
  4. ตรวจโปรไฟล์และ activity heatmap โดยใช้ Tab ไปยังช่องวัน แล้วกด Enter/Space
  5. ทำหรือบันทึกกิจกรรมหนึ่งรายการ รีเฟรช และกลับมาดู heatmap
  6. กด CTA เรียนต่อ
- ผลที่ควรเห็น:
  - Greeting, continue-learning hero และภาพฉากเป็นจุดเด่นก่อนข้อมูลรอง
  - โปรไฟล์ Sea แสดง XP, level, บทที่ผ่านและ streak จากข้อมูลจริง; ผู้ใช้ใหม่เห็นค่าเริ่มต้นเป็นศูนย์
  - Heatmap 20 สัปดาห์เริ่มว่างสำหรับข้อมูลใหม่ และวันที่ที่มีกิจกรรมเปลี่ยนระดับจาก timestamp ที่บันทึกจริง
  - ช่องวัน focus/click ได้และแสดงวันที่กับจำนวนกิจกรรมโดยไม่พึ่ง hover อย่างเดียว
  - ภารกิจเปลี่ยนตามโหมด และโหมดเดิมยังอยู่หลัง refresh
  - Full-stack แสดงเส้นทางเว็บ/Developer, Java แสดง Java Foundations และโหมดผสมแสดงทั้ง step ปัจจุบันกับ route ถัดไป ไม่เหมือน Full-stack เฉย ๆ
  - ในโหมดผสม ให้ผ่าน Developer step แรกแล้วกลับ Home: ภารกิจหลักต้องสลับเป็น Java; เมื่อผ่าน Java step แรกแล้วต้องกลับเป็น Developer step ถัดไป
  - การเปลี่ยนโหมดต้องไม่ค้างชื่อ last step จากอีกเส้นทาง
  - CTA เปิดบทจริง ไม่เปิดหน้าว่าง
