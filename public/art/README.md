# Midnight Pixel Expedition assets

These original assets were generated for Sea's Full-stack Quest with OpenAI image generation on 2026-09-30. No third-party image assets or external repositories were copied.

- `expedition-base.png`: dashboard expedition base scene.
- `miso-sprite-sheet.png`: four consistent robot-cat states (welcome, study, celebrate, rest).
- `world-landmarks.png`: eight world landmarks used by the learning map.

The prompts specified a shared 16-bit pixel-art direction, Midnight Pixel Expedition palette, no text, no logos, and no watermark. Source generation outputs remain in the local Codex generated-images directory; these copies are the production assets used by the app.
